# 卡片设计语言 · 书叶（Book Leaf）

`assets/card_template.html` 的视觉依据。改版式前先读这份，别只照着 CSS 微调数值。

## 1. 设计上下文

| | |
|---|---|
| 受众 | X 信息流里刷到的中文读者，先看到缩略图，点开才看细节 |
| 用途 | 帖子的**补充**，承载卦象、爻辞与传文原文、爻位术语、进程对照 |
| 气质 | 中文古籍的书卷气、印刷质感、克制；与帖子「同路人的见闻，不训话」的口吻一致 |
| 约束 | 1600×900 横版、纯 HTML/CSS、只用仓库里的 `ink_bg.png`、无网络字体、Chromium 无头截图 |

因为卡片是「一叶可以慢读的书」，不是网页也不是海报：不要圆角卡片、不要渐变高光、不要图标拼盘。信息架构由 `conventions.md` 第 4 节固定，这份只管**怎么让它看起来是被设计过的**。

## 3. 改版前的问题 → 对应手法

| 旧版问题 | 改法 |
|---|---|
| 朱红出现在 9 处以上（本爻、两个小标签、要点符号、原文框边线、朱印、topline 方块、foot 高亮…），没有焦点 | **朱红只做两件事**：标出本爻、盖一方印。其余全部交给墨色明度层级 |
| `原文框` 是半透明白底 + 左红彩条，正是 content-guidelines 点名的 AI 卡片签名 | 换成宋刻本式**界栏**：一条细墨竖线 + 缩进，无底色无边框 |
| 「原 文」「所 处 之 位」是拉开字距的红色小标签，模板装饰 | 正常中文字距的墨灰书眉 + 短引线；不再通栏横线，避免表单感 |
| 标题 68px 带 `.09em` 字距，汉字被拉开，松垮 | 70px、字距 `-.01em`；中文标题不用西文 tracking |
| `font-weight: 600` 在只有一档字重的系统字体上被浏览器**合成**，笔画糊成墨团 | `font-synthesis: none`；宁可不强调，不接受变形字形 |
| 左右渐白把水墨底图「洗掉半张」，左栏文字压在山影上 | 水墨只在左半叶透出，交界对齐两栏分隔线；罩色提到 .69～.73 保住注记对比度 |
| 内容顶天立地，地脚几乎没有 | 加一道细版框，版心上提（天头 54px、地脚 66px），底部对照行落在留白上方 |
| foot 的朱红高亮改成墨色下划线后像超链接 | 改用中文原生 `text-emphasis: filled dot`（古籍圈点） |

信息架构一个字没动：六爻卦图、本爻高亮、原文三行、所处之位三条、底部对照行、配置字段全部保持，所以三份示例配置不用改。

## 4. 色彩推导（写得出「为什么」才算过关）

**采样**：从内容自带的材料取色——竹纸、松烟墨、印泥朱批，不凭空发明色板。

**收敛**：一组中性明度序列 + **唯一**一个有彩色。chroma 压低，借用「油墨印在纸上达不到屏幕最大饱和」的物理记忆。

| 角色 | 值 | 用途 |
|---|---|---|
| 纸 | `#f4efe3` / `#f7f2e8` | 卡底、veil 高光 |
| 墨 1 | `#2a2620` | 标题、爻辞首行 |
| 墨 2 | `#4c463c` | 正文、所处之位 |
| 墨 3 | `#6f685b` | 书眉、注记、对照行 |
| 墨 4 | `#8b8172` | 六爻旁注、要点符号、界栏标签 |
| 朱砂 | `#b03325` | **仅**本爻与朱印 |
| 爻条墨 | `#454037 → #2b2822` | 上下渐变 + 两端略深，模拟毛笔起收 |

**论证**：朱砂的本职是「朱笔标出要读的那一处」。把它铺在标签、符号、边线上，等于把标记用成了装饰，本爻反而不再突出。所以红色只留本爻 + 一方印——前者是内容，后者是落款。旧版 `#a64236` 偏暗砖红，换成更接近印泥的 `#b03325`，在本爻高亮上更醒目。

## 5. 排印规则

- 字体 fallback 链：`Noto Serif SC → Noto Serif CJK SC → Songti SC → STSong → SimSun → serif`（小字走 Sans 对应链）。本机未装 Noto CJK，实测回退 Songti 后中文依然清晰。
- `font-synthesis: none`、`line-break: strict`（避头尾）全局开；正文 `text-wrap: pretty`，标题 `text-wrap: balance`。
- 中文标题字距 0 或微负；只有西文全大写小标签才配大正字距。本项目没有这类标签，**不要**再给中文标签加 `.2em`。
- 强调靠字重与墨色深浅，不靠斜体（中文没有 italic，`font-style: italic` 会让汉字机械倾斜）；引文/关键词用着重号。
- 引号用直角「」『』，由配置文本提供，模板不改写。
- 字号层级收敛在 5 档内；两栏总高压在内容区 780px 内（见第 7 节）。

## 6. 版式骨架

```
版框    inset 26px 34px，1px 淡墨细线（宋刻本版框的轻量转译）
内容区  inset 54px 76px 66px 76px → 天头 54 / 地脚 66
左栏    590px，细竖线分隔；水墨透出；书眉 → 六爻卦图 → 位置注记
右栏    书眉 + 朱印 → 爻辞标题 → 细线 → 原文界栏 → 所处之位 → 对照行
```

朱砂配额：**本爻（`.bar.hot` / `.name.hot` / `.note.hot`）＋ `.seal`**，没有第三处。改样式时如果新增了红，先问它是不是在抢本爻。

## 7. 改样式时的红线

1. **`.bar.yin.hot { background: none; }` 不能删**——`.bar.hot` 的红色背景会盖掉阴爻的透明底，让朱红阴爻显示成整条实线。
2. **底部对照行不能用绝对定位**——文本一长就与「所处之位」要点重叠。保持正常文档流，压缩上方间距而不是挪位置。
3. **别把内容区高度改小**——总高已接近 780px 上限，改 `inset` 或加大 margin 会让底部被 `crop(0,0,1600,900)` 切掉。
4. **朱红配额 2 处**，见第 6 节。
5. **别让图像模型写中文**，所有文字由 HTML + 系统字体渲染。
6. 每次改完必须实跑并看图复检。

## 8. 复检

```bash
# 本机需 wrapper（Chrome.app 不在 PATH）与 homebrew python（默认 python3 无 Pillow）
TMPBIN=$(mktemp -d)
printf '#!/bin/sh\nexec "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" "$@"\n' > "$TMPBIN/google-chrome"
chmod +x "$TMPBIN/google-chrome"
for cfg in example_93 example_92 example_kun_chuliu; do
  PATH="$TMPBIN:$PATH" /opt/homebrew/bin/python3 scripts/render_card.py \
    "assets/$cfg.json" --out "/tmp/${cfg}.png"
done
```

看四件事：本爻朱红在正确爻位（坤初六要断成两段）、底部对照行完整不重叠、中文无乱码方框、无明显溢出。三份示例刻意覆盖阳爻危地／阳爻得中／阴爻初爻且无前爻。

## 9. 没有采纳的方向

| 方向 | 为什么没做 |
|---|---|
| 宋刻本全竖排古籍页 | 会推翻现有信息架构，且竖排在 X 缩略图里读不出来 |
| 汉字实验海报（一个巨字占半版） | 需要为每卦造字形，且与「不做意境配图」的克制冲突 |
| 传统色 24 节气色带 | 卡片只有一爻，没有可铺陈的时间轴，色带会变成纯装饰 |
| 多版备选图 | `SKILL.md` 硬规则：一次一张图，不出多版备选 |
