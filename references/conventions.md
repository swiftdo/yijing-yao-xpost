# 完整约定与填写细则

## 1. 图文分工

| | 承担 | 不承担 |
|---|---|---|
| 帖子（主） | 首行标识、当下处境、义理体会、分寸、金句、图文钩子 | 不列卦象图、不列爻位术语、不抄《象》《文言》原文 |
| 卡片（补充） | 六爻卦图、本爻高亮、爻辞与传文原文、「所处之位」三条、对照行 | 不抒发、不写金句、不重复帖子的白话义理 |

同一义理允许两边都出现，但必须**换一套说法**：帖子用白话，卡片用术语与原文。唯一的有意重复是帖子首行（标识锚点）。

## 2. 帖子逐段规则

```
第 1 行   卦 · 爻｜爻辞                 ← 固定，三样信息一次给全
空行
钩子/主体  1～3 段白话，讲义理与处境
空行
收束      一句金句或分寸提醒
空行
图文钩子  卦象与原文见图
标签      #周易 #某卦
```

- **首行格式**：`卦名 · 爻名｜爻辞全文`。例 `乾 · 九二｜见龙在田，利见大人`、`乾 · 九三｜君子终日乾乾，夕惕若厉，无咎`。用全角竖线 `｜`。
- 首行已含爻辞，正文不要再说「这一爻叫某某」——那句是冗余，加首行后必须删。
- **语气**：同路人分享，不是长辈训话。用「不必」「宜」，禁用「切忌」「必须」「切记」。
- **避开**：鸡汤腔、排比堆砌、「在这个快节奏的时代」类套话、AI 味总结句。
- **标签**：固定 2 个，`#周易` + `#某卦`（如 `#乾卦`）。不要第三个。
- **两种可选风格**：白话钩子版（贴近当下处境，传播性好）／克制随笔版（文言白话交融，更贴作者气质）。默认给白话钩子版即可，用户要备选再给第二版。

## 3. X 字数规则（必核）

X 的 280 是**加权字符数**，不是字数：

- 拉丁字母、数字、ASCII 标点、换行 → 1
- CJK 汉字、中文标点、全角符号、emoji → **2**
- 一条纯中文帖最多约 140 字，很容易超

用 `python3 scripts/wlen.py <帖子文本或文件路径>` 核算，**必须 ≤280，建议 ≤275** 留余量。超限就删句，不要扩写、不要拆成两条。常见省字手法：删与首行重复的引入句、金句收紧、把「也不必」并成「不必」。

## 4. 卡片版式规格

| 项 | 值 |
|---|---|
| 尺寸 | 1600×900（16:9），X 不二次裁切 |
| 底图 | `assets/ink_bg.png`（1536×944，已去水印），`cover` 铺满 |
| 罩色 | 左到右米白渐变 `rgba(247,244,237,.56)` → `rgba(249,247,240,.98)` |
| 字体 | 正文 `Noto Serif CJK SC`，标签小字 `Noto Sans CJK SC` |
| 主色 | 墨 `#2f2c26`／`#4a463e`；朱红 `#a64236`（本爻、印、左边线） |
| 内容区 | `inset: 56px 70px`，左栏 590px + 竖分隔线 + 右栏 |
| 输出 | `/workspace/{卦名}{爻名}_知识卡片_封面.png` |

左栏：`卦名 · 第N卦` → `X下Y上 · 说明` → 六爻卦图（自下而上，第 3 爻后虚线分上下卦，本爻朱红）→ 两行位置注记（第二行用 `<b>` 标关键词）。

右栏：`爻名 · 爻辞` + 朱印（卦名一字）→ 爻辞标题两行 → 细线 → 「原 文」框（爻辞、《象》、可选《文言》节引）→ 「所 处 之 位」三条 → 底部对照行。

## 5. 易学考据规则

- **必核**：爻辞与《象》逐字准确，联网查权威文本（维基文库《周易》、识典古籍等）。断句有异文时从通行本（如「夕惕若厉，无咎」）。
- **《文言》只有乾、坤两卦有**。其余卦 `src3` 留空数组，模板会自动省略该行，不要硬凑。
- **节引**必须用「……」标明，例「……君德也」；不要伪装成逐字全引。
- **爻名规则**：阳爻称「九」，阴爻称「六」；位序自下而上为 初／二／三／四／五／上。例：初九、九二、六二、六五、上六。
- **卦图**：阳爻整条实线，阴爻断开两段；`yao_lines` 在配置里按**从上到下**排列（上爻在前），脚本自动在第 3 行后插分界线、按 `hot_from_bottom` 定位本爻。
- **位置解读避争议**：不写三才归属（初二为地等有异说）、不写当位／失位（易家分歧大）。只用注家共识：二为臣位、五为君位、二五得中、下卦之上为危地等。
- **优先引用**《文言》中直接讲爻位的句子（如九三「重刚而不中，上不在天，下不在田」），比泛泛的义理更贴「所处位置」这个主题。
- 底部对照行取**前一爻**的爻辞关键词 → 本爻，形成六爻进程感。**本爻为初爻时无前爻**：改用对卦初爻对举（如坤初六写「乾初九「潜龙勿用」 → 坤初六「履霜」」，合于乾坤并列之例），或写「本卦卦辞 → 初爻」；不要凭空捏一个不存在的前爻。

## 6. 配置字段（assets/example_92.json / 93.json 可直接改）

| 字段 | 说明 |
|---|---|
| `out` | 输出文件名（写到 `/workspace`） |
| `gua_label` / `guaxiang` | 左栏两行，如「乾卦 · 第一卦」「乾下乾上 · 六阳纯刚」 |
| `split_label` | 分界线文字，按该卦上下卦名填，如「上卦（外）乾 ／ 下卦（内）乾」 |
| `tag` / `seal` | 右栏标签「九三 · 爻辞」、朱印单字（卦名） |
| `title` | 爻辞拆成两行的数组 |
| `src1` / `src2` / `src3` | 爻辞、《象》、《文言》节引两行数组（`src3: []` 表示无《文言》） |
| `points` | 「所处之位」三条，纯文本 |
| `foot1` / `foot2` | 左栏两行注记，`foot2` 可用 `<b>…</b>` 高亮 |
| `bottom` | 对照行 |
| `hot_from_bottom` | 本爻是自下而上第几爻（1～6） |
| `hot_note` | 本爻右侧标注，如「◀ 本爻 · 得中」 |
| `yao_lines` | 六行，自上而下；每行 `name`、`yin`(bool)、`note` |

配置里允许简单 HTML（`<b>`、`<br>` 由脚本处理），其余文字不要含尖括号。

## 7. 踩坑清单

1. **浏览器裁切**：`chromium --headless=new --window-size=1600,1000` 的实际可视高约 913，不是 1000。所以卡片必须按 900 设计，截图后 `crop(0,0,1600,900)`；否则底部文字会被切掉上半截。
2. **底部行别用绝对定位**：曾用 `position:absolute; bottom:0` 放「对照」行，文本一长就与「所处之位」要点重叠。模板已改正常文档流并压缩间距，两栏总高控制在内容区 788px 内。
3. **别让图像模型写中文**：AI 生成的中文必乱码，所有文字由 HTML + 系统字体渲染。
4. **底图水印**：平台生成图右下角带「AI生成」水印，已裁掉底部 80px。直接用 `assets/ink_bg.png`，不要再调图像生成。
5. **复检不可省**：每次渲染后看一眼图，确认高亮爻位正确、底部完整、无重叠。
6. **阴爻高亮的 CSS 特异性**：`.bar.hot` 的红色背景会盖掉 `.bar.yin` 的透明底，让朱红阴爻显示成整条实线。模板里已加 `.bar.yin.hot { background: none; }`，改样式时别删这一行。
