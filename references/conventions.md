# 完整约定与填写细则

## 1. 图文分工

| | 承担 | 不承担 |
|---|---|---|
| 帖子（主） | 首行标识、误读纠偏、当下处境、具体动作与画面 | 不列卦象图、不列爻位术语、不抄《象》《文言》原文，不写看图提示，不做说教 |
| 卡片（补充） | 六爻卦图、本爻高亮、爻辞与传文原文、「所处之位」三条、对照行 | 不抒发、不写金句、不重复帖子的白话义理 |

同一义理允许两边都出现，但必须**换一套说法**：帖子用白话，卡片用术语与原文。唯一的有意重复是帖子首行（标识锚点）。

## 2. 帖子逐段规则

```
第 1 行   卦 · 爻｜爻辞                 ← 固定，三样信息一次给全
空行
翻转      这爻常被怎么误读 → 更准的读法    ← 帖子的信息增量，一到两句
空行
主体      1～3 段具体处境、动作、画面
空行
接续      指向下一爻的一句事实陈述        ← 可选，不预告吉凶
空行
标签      #周易 #某卦
```

### 2.1 翻转句（必做，帖子的核）

一条帖子光有处境不够——那是抒情；读完要么改了看法，要么什么也没留下。**翻转句就是那个「改了看法」**：

- **是什么**：`「终日乾乾」常被当成励志句。它写的不是勤奋，是不敢停。` 先摆出这爻最常见的读法，再给出更准的读法。
- **为什么不算说教**：它判断的是**文本**，不是读者。说「这四个字常被读成防微杜渐」是在纠一个解法，说「你不该急功近利」才是在教训人。前者是信息，后者是训话。
- **必须是真的**：搜一次白话解读，确认大众版本确实这么说（多半是励志化或道德化），再写。不许为了凑一个翻转而编造误读。
- **要短**：一到两句。写成三四段的小论文就本末倒置了。
- **找不到明显误读时**，改用**单字重译**：抓爻辞里一个关键词，用现代口语把它拆开。例：九二的「见」拆成「被看见」与「被任用」——`见，也不等于用。`

### 2.2 接续句（可选）

结尾指向下一爻的一件事实，用来把单条帖子接进连载：

- 只陈述事实：`再往上一步是九四：那一步，是跳。`
- **不预告吉凶、不吊胃口、不写「下期见」**。
- 结尾已有强画面时可以省掉——不要为了接续把画面冲淡（见 `examples.md` 例 3）。
- 上爻（上九／上六）没有下一爻：改为回指初爻，或直接省。

### 2.3 首行与语气

- **首行格式**：`卦名 · 爻名｜爻辞全文`。例 `乾 · 九二｜见龙在田，利见大人`、`乾 · 九三｜君子终日乾乾，夕惕若厉，无咎`。用全角竖线 `｜`。
- 首行已含爻辞，正文不要再说「这一爻叫某某」——那句是冗余，加首行后必须删。
- **语气：同路人的见闻，不是长辈的叮嘱**。**不劝告、不下指令、不下判断**：
  - 禁用「切忌／必须／切记」，也**不用「宜」「不必」「应该」「要记得」「就够了」「能做的只有一件」**——这些同样是在教人做事。
  - 少用「这一爻讲的是 X」「说明了一个道理」「难的从来不是 A，是 B」这类全知口吻；判断留给读的人。
  - 注意：**翻转句不在此列**。说「这四个字常被读成 X」判断的是文本，不是读者，正是允许的那种判断。
  - 改用具体的处境、动作、画面：写「话传得比人快，位子没跟上」，不写「不必争名分」；写「有人蹲下来看了看，然后照旧赶路」，不写「顺着它看一眼就够了」。
  - 结尾用留白、画面或接续句，**不写箴言式金句**、不给分寸提醒。
- **避开**：鸡汤腔、排比堆砌、「在这个快节奏的时代」类套话、AI 味总结句、教训口吻。
- **标签**：固定 2 个，`#周易` + `#某卦`（如 `#乾卦`）。不要第三个。
- **不写看图提示**：已废弃「卦象与原文见图」这类占位句——附图本身已说明，无需在正文里再提一次。删掉它省下约 18 加权字符，**用来把处境、动作写具体**（如「这时候没人替你兜底」），篇幅别空着，也别塞套话凑数。
- **两种可选风格**：**翻转版**（默认，误读纠偏 + 处境白描，传播性最好）／**克制随笔版**（没有明显误读时改用单字重译，篇幅更短、更贴作者气质）。默认给翻转版即可，用户要备选再给第二版。

## 3. X 字数规则（必核）

X 的 280 是**加权字符数**，不是字数：

- 拉丁字母、数字、ASCII 标点、换行 → 1
- CJK 汉字、中文标点、全角符号、emoji → **2**
- 一条纯中文帖最多约 140 字，很容易超

用 `python3 scripts/wlen.py <帖子文本或文件路径>` 核算，**必须 ≤280，建议 ≤275** 留余量。超限就删句，不要扩写、不要拆成两条。常见省字手法：删与首行重复的引入句、收紧铺陈、合并同义的动作描写。

## 4. 卡片版式规格

| 项 | 值 |
|---|---|
| 尺寸 | 1600×900（16:9），X 不二次裁切 |
| 底图 | `assets/ink_bg.png`（1536×944，已去水印），`left center / cover`，只在左半叶透出 |
| 罩色 | 左 `.69` → 43% 处 `.93` → 右 `.985` 的暖纸渐变，外加极淡四角暗角 |
| 版框 | `inset: 26px 34px`，1px 淡墨细线（宋刻本版框的轻量转译） |
| 字体 | 正文 `Noto Serif SC` → `Noto Serif CJK SC` → `Songti SC` fallback 链；小字走 Sans 对应链；`font-synthesis: none`、`line-break: strict` |
| 主色 | 纸 `#f4efe3`；墨 `#2a2620`／`#4c463c`／`#6f685b`／`#8b8172` 四级；朱砂 `#b03325` **仅本爻与朱印两处** |
| 内容区 | `inset: 54px 76px 66px 76px`（天头小、地脚大），左栏 590px + 细竖分隔线 + 右栏 |
| 输出 | `/workspace/{卦名}{爻名}_知识卡片_封面.png`（本机根不可写时显式传 `--out`） |

左栏：`卦名 · 第N卦` → `X下Y上 · 说明` → 六爻卦图（自下而上，第 3 爻后虚线分上下卦，本爻朱砂）→ 两行位置注记（第二行用 `<b>` 出中文着重号）。

右栏：`爻名 · 爻辞` + 朱印（卦名一字）→ 爻辞标题两行 → 细线 → 原文界栏（爻辞、《象》、可选《文言》节引）→ 所处之位三条 → 底部对照行。

视觉依据、色彩推导与改样式红线见 **`references/card-design.md`**，改模板前先读。

## 5. 易学考据规则

- **必核**：爻辞与《象》逐字准确，联网查权威文本（维基文库《周易》、识典古籍等）。断句有异文时从通行本（如「夕惕若厉，无咎」）。
- **《文言》只有乾、坤两卦有**。其余卦 `src3` 留空数组，模板会自动省略该行，不要硬凑。
- **节引**必须用「……」标明，例「……君德也」；不要伪装成逐字全引。
- **爻名规则**：阳爻称「九」，阴爻称「六」；位序自下而上为 初／二／三／四／五／上。例：初九、九二、六二、六五、上六。
- **卦图**：阳爻整条实线，阴爻断开两段；`yao_lines` 在配置里按**从上到下**排列（上爻在前），脚本自动在第 3 行后插分界线、按 `hot_from_bottom` 定位本爻。
- **位置解读避争议**：不写三才归属（初二为地等有异说）、不写当位／失位（易家分歧大）。只用注家共识：二为臣位、五为君位、二五得中、下卦之上为危地等。
- **优先引用**《文言》中直接讲爻位的句子（如九三「重刚而不中，上不在天，下不在田」），比泛泛的义理更贴「所处位置」这个主题。
- 底部对照行取**前一爻**的爻辞关键词 → 本爻，形成六爻进程感。**本爻为初爻时无前爻**：改用对卦初爻对举（如坤初六写「乾初九「潜龙勿用」 → 坤初六「履霜」」，合于乾坤并列之例），或写「本卦卦辞 → 初爻」；不要凭空捏一个不存在的前爻。

配置里允许简单 HTML（`<b>`、`<br>` 由脚本处理），其余文字不要含尖括号。

## 7. 踩坑清单

1. **浏览器裁切**：`chromium --headless=new --window-size=1600,1000` 的实际可视高约 913，不是 1000。所以卡片必须按 900 设计，截图后 `crop(0,0,1600,900)`；否则底部文字会被切掉上半截。
2. **底部行别用绝对定位**：曾用 `position:absolute; bottom:0` 放「对照」行，文本一长就与「所处之位」要点重叠。模板已改正常文档流并压缩间距，两栏总高控制在内容区 780px 内；改 `inset` 或加大上间距都可能让底行被裁。
3. **别让图像模型写中文**：AI 生成的中文必乱码，所有文字由 HTML + 系统字体渲染。
4. **底图水印**：平台生成图右下角带「AI生成」水印，已裁掉底部 80px。直接用 `assets/ink_bg.png`，不要再调图像生成。
5. **复检不可省**：每次渲染后看一眼图，确认高亮爻位正确、底部完整、无重叠。
6. **阴爻高亮的 CSS 特异性**：`.bar.hot` 的红色背景会盖掉 `.bar.yin` 的透明底，让朱红阴爻显示成整条实线。模板里已加 `.bar.yin.hot { background: none; }`，改样式时别删这一行。
7. **朱红配额只有两处**：本爻与朱印。给标签、要点符号、边线加红，本爻就不再是最强音；要强调层级请改墨色明度或字重（`references/card-design.md` 第 4、6 节）。
8. **中文别套西文排印**：标题不要 `.09em` 大正字距、中文小标签不要 `.26em`；`font-synthesis: none` 别删，否则只有一档字重的系统字体会被合成出糊成墨团的假粗体。
