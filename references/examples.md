# 成例

五份成例、六条帖子，换卦时照此重写。卡片配置全文见 `assets/example_92.json`、`assets/example_93.json`、`assets/example_94.json`、`assets/example_kun_chuliu.json` 与 `assets/example_kun_liusan.json`。

三条约定贯穿全部成例：

1. 帖子末尾**只有标签**，不写「卦象与原文见图」。
2. 正文是**同路人的见闻，不是长辈的叮嘱**——只写处境、动作、画面，不劝告、不下指令、不写箴言。
3. 帖子要有一个**信息增量**：指出这爻常被怎么误读，再给出更准的读法。判断落在**文本**上，不落在读者身上。

第 3 条是这批成例改写的重点。详见 `conventions.md` 第 2 节。

五条贯穿所有成例的硬口径（也都是被用户否过之后才定下来的）：

- **翻转句说白话，判断是一句完整的话**：能单独转述给别人的才算判断；「变的只是名声」「没定，不算错」这类压缩短语，读者接住了也不知道拿它做什么。
- **主体从读者角度切入**：`桌上那份 offer 还没签，笔帽没拔` 胜过 `脚已经站到边上`。
- **场景几行连成一件事**：行与行之间答得上「所以呢／后来呢」，不是几张孤立画面的拼贴。
- **结尾用画面或判词收束**，判词也要完整成句；不写「再往上一步是九四」这类接续句。
- 篇幅吃紧时先删解释、再删形容词，**不删具体动作**。

2026-11-16 这批帖子全部重写过一轮：病根是「紧缩句拼贴＋压缩短语判断」——句子看着短、节奏看着快，但每一处都要读者自己补全，读起来反而拗口，核心传不出来。病句与改法对照见 `conventions.md` 2.0～2.3。

## 例 1 · 乾卦九二

**帖子（主推，237 加权字符）**

```
乾 · 九二｜见龙在田，利见大人

「利见大人」常被读成找靠山。其实方向反了——本事摆到了明处，该是别人来见你。

位子还没动，人已经一个个找上门来。
谈的都是正事，谈定一件是一件。走的时候，没一个是空手的。

凳子没挪，收获倒先到了。

#周易 #乾卦
```

**手法拆解**：翻转句纠正的是「利见大人＝找靠山」这个常见解法，不是劝人别攀附；给出的正读本身就是这四个字的白话——本事摆到明处，别人来见你。这一读法从《象》「德施普也」来：德先让人看见，位子不必先动。场景三行是一条事的三步（位子没动而人先上门 → 谈的是正事 → 走的人没空手），「德施普也」不说破，全在「没一个空手的」里。旧版被否掉的两处正是病根：「话传得比人快，位子没跟上。有人听，也在掂量」是紧缩句拼贴，谁在传、谁在掂量都没说清；「名片递完一圈」更与翻转自相矛盾——递名片恰恰是找靠山的动作，核心传不出去就在这里。

**备选 · 克制随笔版（245，无翻转、靠单字重译）**

```
乾 · 九二｜见龙在田，利见大人

「勿用」是没人用，「利见」是有人肯见。
中间隔着的不是本事，是时位。

田不是朝堂。见，也不等于用。
那阵子来往的多是同道，谈的都是手上做的事。
名字先传开了，位子还在后头。散席之后，照旧走回自己那间屋子。

#周易 #乾卦
```

「见」在这里被拆成「被看见」与「被任用」两层——一个字的重译，替代整段误读纠正。适合爻辞本身没有明显误读、但有字义落差的情况。开头的「勿用」「利见」先各自用一句白话说清（没人用／有人肯见），再下判断：**引文言必译**，不带解释的文言词是硬伤。

**卡片配置要点**：`hot_from_bottom: 2`、`hot_note: "◀ 本爻 · 得中"`；`trans1` 给「见龙在田，利见大人」的白话，`trans2` 给《象》的白话；`src3` 用《文言》节引一句并带「……」；三条「所处之位」讲下卦之中得中、二为臣位、出潜离隐。完整配置 → `assets/example_92.json`。

## 例 2 · 乾卦九三

**帖子（主推，270 加权字符）**

```
乾 · 九三｜君子终日乾乾，夕惕若厉，无咎

「终日乾乾」常被当成励志句。它写的不是勤奋，是不敢停。

你爬到半山腰，上不着天，下不着地。
白天做到天黑，夜里还提着心。躺下了，脑子还在过白天的事。
没人替你兜底，稍一松劲就可能出事。

闹钟定在六点，睡前又核对了一遍。

#周易 #乾卦
```

**手法拆解**：整句爻辞的常见误读是「勤奋奋斗」，翻转成「不敢停」——勤奋是主动加班，不敢停是身处险地的本能反应，这个落差就是信息增量。场景这轮补了处境定位：「半山腰，上不着天，下不着地」就是《文言》「上不在天，下不在田」的白话，放进场景里说，不引原文。三行是一条线：先定位（为什么难）→ 全天提着心（终日乾乾、夕惕）→ 没人兜底所以松不得（若厉），行与行之间「所以呢」都接得上。旧版把「六爻里只有这一爻谈君子」缀在翻转后面，翻转段挤成三句，读着就散——这类文本观察要么并进第二句，要么删（2.0「不写旁白」）。结尾还是闹钟：那种怕睡过的紧，比「警惕」两个字具体。

**卡片配置要点**：`hot_from_bottom: 3`、`hot_note: "◀ 本爻 · 重刚不中"`；「所处之位」三条按下卦之上／上不在天下不在田／进德修业来写；`src3` 选《文言》「九三重刚而不中，上不在天，下不在田」——这句本身就是讲爻位的，最贴「所处位置」主题。`trans1` 把「终日乾乾，夕惕若厉，无咎」翻成白话（整天勤勉不松劲，到夜里还提着心；虽在险处，也不至出错），`trans2` 翻《象》的「反复道也」。完整配置 → `assets/example_93.json`。

## 例 3 · 坤卦初六（阴爻／初爻／有《文言》）

覆盖三个易错点：全阴爻、本爻是第一爻（无前爻可对照）、坤卦有《文言》。

**帖子（272 加权字符）**

```
坤 · 初六｜履霜，坚冰至

常被读成防微杜渐的教训。其实它在说：霜和冰之间，隔着整整一个冬天。

踩到霜那天，天还没真冷。
门槛背阴处白得早一点，谁也没当回事。
日子照旧过着，地面一天比一天硬，谁也没看见。

等到冰封上来，回头一看。冰不是哪天冻上的，是一天天走到的。

#周易 #坤卦
```

**手法拆解**：翻转不变——防微杜渐 → 霜和冰之间隔着一整个冬天，把教训变成时间差。场景三行是一条线：踩到霜（起）→ 背阴处白得早（没人当回事）→ 地面一天比一天硬（没看见）。「谁也没当回事」「谁也没看见」两处同构是有意的：中间那段日子正是这样过去的，末句「回头一看」才接得住。判词这轮换了：旧版「中间那些日子全是空着的」是压缩短语，读者不知道「空着」意味着什么；新版「冰不是哪天冻上的，是一天天走到的」把《象》「驯致其道」翻成完整的一句——冰是一条路走到头的，没有哪一天是转折点。

这份的收束是**判词**不是画面：它从《象》里读出来，不是作者的开解。不写「再往上一步是六二」，道理同前（2.3）。

**卡片配置要点**：六行 `yin: true`（阴爻画断开两段）；`hot_from_bottom: 1`；坤卦有《文言》，`src3` 用「……非一朝一夕之故，其所由来者渐矣」——讲「渐」，最贴初六见微知著的主题；初六无前爻，`bottom` 改**乾坤对举**「乾初九「潜龙勿用」 → 坤初六「履霜」」。`src2` 是全篇最长的一行（《象》两句），渲染后重点看图确认版面没被顶破；`trans2` 照它翻成白话。完整配置 → `assets/example_kun_chuliu.json`。

## 例 4 · 乾卦九四（读者角度 · 判词收束）

这一份是「朴实」与「从读者角度」两条口径的样板：全篇没有一个训诂术语，场景是读者桌上正在发生的事。

**帖子（273 加权字符）**

```
乾 · 九四｜或跃在渊，无咎

「或跃在渊」常被讲成进退自如。其实「或」是「也许」——跳得上去，也可能不跳。

桌上那份 offer 还没签，笔帽没拔。
有人问起，只说再看看。
夜里躺下，想的不是去了怎么干，是万一不成怎么回来。

爻辞给的判词是「无咎」：试着往上跳，本身不算错。

#周易 #乾卦
```

**手法拆解**：

- **翻转只拆一个字**：「或」=「也许」（「跳得上去，也可能不跳」）。通行解读（百度百科、易德轩、高岛易断等）都把这爻讲成「审时度势、进退自如的从容」，可《文言》原话是「或之者，疑之也」——这里只留结论，不留训诂，**先删掉「《文言》说……」那半句，字数才是最省的**。
- **三行场景全在读者这一侧**，且一条线贯穿：那份没签的 offer → 被问起只说再看看 → 夜里算的是退路。没有一句「他站在边上」。
- **判词这轮换了**：旧版「没定，不算错」是两个短语缩在一起——什么没定？什么不算错？读者接不住；《象》「进无咎也」判的也不是「不定」，是「进」本身。新版「试着往上跳，本身不算错」是一句完整判词，正好对着场景里「万一不成怎么回来」的怕——爻辞只判了往前那一步。不写「再往上一步是九五：那一爻，在天上」——读者读完那三行就够了。

**卡片配置要点**：`hot_from_bottom: 4`；标题两行「或跃在渊／无咎」；`src3` 节引「九四重刚而不中……故或之。或之者，疑之也。」——中段「上不在天，下不在田，中不在人」被省掉，交给「所处之位」第二条讲；`trans2` 只译「进无咎也」（往前进一步，本身没有过错），不要加「审时而后进」这类增字。《文言》原话与帖子里的判词指向同一处，但不重复措辞。完整配置 → `assets/example_94.json`。

## 例 5 · 坤卦六三（阴爻／下卦之上／有《文言》）

覆盖：全阴爻居三、下卦之上的进退之际、对照行正常对举；`trans1` 放开到两行——「译文不限一行」口径的实测样例。

**帖子（266 加权字符）**

```
坤 · 六三｜含章可贞，或从王事，无成有终

「含章」常被读成韬晦：才华收着，别抢功。其实那不是藏，是美含在里头，到时候自然发。

方案写了一个季度，署名却是部门的名字。
问起来，只说在推进。
收尾的活没人愿意接，补完的还是你。

事情不是你成的，走到底的却是你。

#周易 #坤卦
```

**手法拆解**：大众版把这爻讲成韬光养晦——才华收着，别锋芒太露，防的是上司疑忌。翻转只拆「含章」一个词：不是藏，是美在里头，到时候自然发（对应《象》「以时发也」），把处世技巧还原成时机；第二句就是判断，且是完整句。旧版后半句「是美在里头，等该它出来的时候」三层意思挤在一起、读着绕，这轮收紧成一句。场景砍掉冗字（「交上去那天」并进「署名却是」），三行还是一条事：写方案 → 被问起 → 补收尾。收束是「无成有终」的白话判词，不引术语——事情不是你成的，可走到底的是你，这层意思本来就在爻辞里，不是作者的开解。

**卡片配置要点**：`hot_from_bottom: 3`；六行 `yin: true`；`src3` 节引「阴虽有美，含之以从王事，弗敢成也……地道无成，而代有终也」——前半讲含、后半讲终，正好接住爻辞两头。`trans1` 按「说得明白」放开写：47 字折两行，实测右栏余 44px；旧口径下这句会被压成约 20 字的概括。完整配置 → `assets/example_kun_liusan.json`。

## 换卦时

1. 联网核对新爻的爻辞与《象》，**并写下爻辞与《象》的白话译文**（`trans1` / `trans2`）；非乾、坤则 `src3: []`。
2. **先找这爻的常见误读**：搜一次白话解读，看大众版本怎么说（多半是励志化或道德化的）。找到落差就写翻转句；找不到明显误读，就抓爻辞里一个字做重译。**翻转句用白话写，判断是一句完整的话，不搬训诂**。
3. **把处境换成读者的场景**：不问「这一爻在讲谁」，问「读者哪一天会撞上这件事」——跳槽、竞聘、被问要不要接、等一个还没下来的消息。挑一种就够，写具体的物（笔帽、闹钟、署名栏）。
4. 按首行格式重写帖子：翻转句一到两句（第二句的判断要完整成句）→ 读者能对上的场景（几行连成一件事）→ **一句画面或判词收束**（判词也要完整成句）→ 两个标签。**帖子里每引一处文言词句，紧跟一句白话把它说清**；不劝告、不总结，核字数 ≤275。
5. 复制一份 JSON，改卦名、卦象说明、六爻阴阳与本爻位置、原文与译文、三条解读、对照行；**本爻为初爻时用对卦对举写对照行**。
6. 跑 `render_card.py`，看图复检：译文是否与原文逐句对应、是否说得明白（允许折行）、底部是否被裁。
7. 可直接选用成例：`example_92.json`（阳爻·得中）、`example_93.json`（阳爻·危地）、`example_94.json`（阳爻·上卦之下·重刚不中）、`example_kun_chuliu.json`（阴爻·初爻·有《文言》）、`example_kun_liusan.json`（阴爻·下卦之上·有《文言》）。
