# 成例

三份完整产出，换卦时照此重写。卡片配置全文见 `assets/example_92.json`、`assets/example_93.json` 与 `assets/example_kun_chuliu.json`。

两份约定贯穿全部成例：帖子末尾**只有标签，不写「卦象与原文见图」**；正文是**同路人的见闻，不是长辈的叮嘱**——只写处境、动作、画面，不劝告、不下指令、不写箴言。见 `conventions.md` 第 2 节。

## 例 1 · 乾卦九二

**帖子（主推，273 加权字符）**

```
乾 · 九二｜见龙在田，利见大人

熬过没人看见的日子，终于有人愿意听你说话了。

被看见之后，还有一段日子：
有本事，却还没到那个位子；
有人听，也在掂量。
话传得比人快，位子没跟上。

常来往的还是几个肯说实话的人，
手上的事一件件交出去。
那把椅子空着，席间没人提起。

#周易 #乾卦
```

**备选 · 克制随笔版（247）**

```
乾 · 九二｜见龙在田，利见大人

从「勿用」到「利见」，隔着的，好像不是本事，是时位。

初九沉潜，九二光华初见于田——
有德有才，却未居尊。
田不是朝堂，见也不等于用。

那阵子来往的多是同道，谈的都是手上做的事。
名字先传开了，位子还在后头。

#周易 #乾卦
```

**卡片配置要点**：`hot_from_bottom: 2`、`hot_note: "◀ 本爻 · 得中"`；`src3` 用《文言》节引并带「……」；三条「所处之位」讲下卦之中得中、二为臣位、出潜离隐。完整配置 → `assets/example_92.json`。

## 例 2 · 乾卦九三

**帖子（267 加权字符）**

```
乾 · 九三｜君子终日乾乾，夕惕若厉，无咎

被看见了，却还没到那个位子——比蛰伏更难熬。

往上够不着，往下也落不稳，进退都悬着。
这时候没人替你兜底。
白天连着夜里不敢松劲，躺下了脑子还在过白天的事。

九三不谈龙，只谈「君子」。
翻来覆去说的，是危地上怎么站住。

#周易 #乾卦
```

**卡片配置要点**：`hot_from_bottom: 3`、`hot_note: "◀ 本爻 · 重刚不中"`；「所处之位」三条按下卦之上／上不在天下不在田／进德修业来写；`src3` 选《文言》「九三重刚而不中，上不在天，下不在田。故乾乾因其时而惕，虽危无咎矣」——这句本身就是讲爻位的，最贴「所处位置」主题。完整配置 → `assets/example_93.json`。

## 例 3 · 坤卦初六（阴爻／初爻／有《文言》）

覆盖三个易错点：全阴爻、本爻是第一爻（无前爻可对照）、坤卦有《文言》。

**帖子（262 加权字符）**

```
坤 · 初六｜履霜，坚冰至

脚下不过一层薄霜，天还没真冷。
只是后来收不住的事，起头都这么轻。

那时候谁也没把它当回事：
苗头小到不值得声张，也就小到没人肯当真。
门槛背阴处，比别处白得早一点。

没人惊慌，也没人特意提起。
有人蹲下来看了看，然后照旧赶路。

#周易 #坤卦
```

**卡片配置要点**：六行 `yin: true`（阴爻画断开两段）；`hot_from_bottom: 1`；坤卦有《文言》，`src3` 用「……非一朝一夕之故，其所由来者渐矣，／由辩之不早辩也。易曰：「履霜，坚冰至。」盖言顺也。」——讲「渐」与「辨之于早」，最贴初六见微知著的主题；初六无前爻，`bottom` 改**乾坤对举**「乾初九「潜龙勿用」 → 坤初六「履霜」」。完整配置 → `assets/example_kun_chuliu.json`。

## 换卦时

1. 联网核对新爻的爻辞与《象》；非乾、坤则 `src3: []`。
2. 按首行格式重写帖子：末尾只留两个标签，用叙述和白描把篇幅给正文，不劝告、不总结，核字数 ≤275。
3. 复制一份 JSON，改卦名、卦象说明、六爻阴阳与本爻位置、原文、三条解读、对照行；**本爻为初爻时用对卦对举写对照行**。
4. 跑 `render_card.py`，看图复检。
5. 可直接选用成例：`example_92.json`（阳爻·得中）、`example_93.json`（阳爻·危地）、`example_kun_chuliu.json`（阴爻·初爻·有《文言》）。
