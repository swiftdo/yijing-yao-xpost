# 成例

四份完整产出，换卦时照此重写。卡片配置全文见 `assets/example_92.json`、`assets/example_93.json` 与 `assets/example_kun_chuliu.json`。

三条约定贯穿全部成例：

1. 帖子末尾**只有标签**，不写「卦象与原文见图」。
2. 正文是**同路人的见闻，不是长辈的叮嘱**——只写处境、动作、画面，不劝告、不下指令、不写箴言。
3. 帖子要有一个**信息增量**：指出这爻常被怎么误读，再给出更准的读法。判断落在**文本**上，不落在读者身上。

第 3 条是这四份成例改写的重点。详见 `conventions.md` 第 2 节。

## 例 1 · 乾卦九二

**帖子（主推，270 加权字符）**

```
乾 · 九二｜见龙在田，利见大人

「利见大人」常被读成找靠山。九二没挪位，变的只是名声。

田不是朝堂，有德有才，位置还在原处。
话传得比人快，位子没跟上。有人听，也在掂量。
常来往的还是几个肯说实话的人，手上的事一件件交出去。

再往上一步是九三：夜里的那种提心。

#周易 #乾卦
```

**手法拆解**：翻转句说「常被读成找靠山」，纠正的是**这句话的常见解法**，不是在劝读者别攀附。接着三句全是可指认的动作（话传得快、位子没跟上、事一件件交出去），没有一句评价。末句指向九三，只报事实，不预告吉凶。

**备选 · 克制随笔版（226，无翻转、靠单字重译）**

```
乾 · 九二｜见龙在田，利见大人

从「勿用」到「利见」，隔着的不是本事，是时位。

田不是朝堂。见，也不等于用。
那阵子来往的多是同道，谈的都是手上做的事。
名字先传开了，位子还在后头。散席之后，他照旧走回自己那间屋子。

#周易 #乾卦
```

「见」在这里被拆成「被看见」与「被任用」两层——一个字的重译，替代整段误读纠正。适合爻辞本身没有明显误读、但有字义落差的情况。

**卡片配置要点**：`hot_from_bottom: 2`、`hot_note: "◀ 本爻 · 得中"`；`src3` 用《文言》节引并带「……」；三条「所处之位」讲下卦之中得中、二为臣位、出潜离隐。完整配置 → `assets/example_92.json`。

## 例 2 · 乾卦九三

**帖子（272 加权字符）**

```
乾 · 九三｜君子终日乾乾，夕惕若厉，无咎

「终日乾乾」常被当成励志句。它写的不是勤奋，是不敢停。

白天做到晚，夜里还提着心——躺下了，脑子还在过白天的事。
往上够不着，往下也落不稳，这时候没人替你兜底。

九三不谈龙，只谈「君子」。
再往上一步是九四：那一步，是跳。

#周易 #乾卦
```

**手法拆解**：整句爻辞的常见误读是「勤奋奋斗」，翻转成「不敢停」——差别在主动与被动，这就是信息增量。「不上不下」用两句写，第三句「没人替你兜底」是处境，不是抱怨。末句「那一步，是跳」只对应「或跃在渊」的字面，不下判断。

**卡片配置要点**：`hot_from_bottom: 3`、`hot_note: "◀ 本爻 · 重刚不中"`；「所处之位」三条按下卦之上／上不在天下不在田／进德修业来写；`src3` 选《文言》「九三重刚而不中，上不在天，下不在田。故乾乾因其时而惕，虽危无咎矣」——这句本身就是讲爻位的，最贴「所处位置」主题。完整配置 → `assets/example_93.json`。

## 例 3 · 坤卦初六（阴爻／初爻／有《文言》）

覆盖三个易错点：全阴爻、本爻是第一爻（无前爻可对照）、坤卦有《文言》。

**帖子（272 加权字符）**

```
坤 · 初六｜履霜，坚冰至

常被读成防微杜渐的教训。它其实在说一件事：霜和冰之间，隔着整整一个冬天。

踩到霜那天，天还没真冷。
门槛背阴处比别处白得早一点，谁也没把它当回事。
苗头小到不值得声张，也就小到没人肯当真。

等到冰封上来，回头看，中间那些日子全是空着的。

#周易 #坤卦
```

**手法拆解**：这爻最容易被读成「要防微杜渐」——一句训人的话。翻转成「霜和冰之间隔着一个冬天」，把教训变成**时间差**：危险不在霜，在霜与冰之间那段没人当回事的日子。末句不给提醒，只留一个画面。

这一份**故意不写接续句**：结尾的画面已经足够，再加「再往上一步是六二」会把它冲淡。接续句是可选的，见 `conventions.md`。

**卡片配置要点**：六行 `yin: true`（阴爻画断开两段）；`hot_from_bottom: 1`；坤卦有《文言》，`src3` 用「……非一朝一夕之故，其所由来者渐矣，／由辩之不早辩也。易曰：「履霜，坚冰至。」盖言顺也。」——讲「渐」与「辨之于早」，最贴初六见微知著的主题；初六无前爻，`bottom` 改**乾坤对举**「乾初九「潜龙勿用」 → 坤初六「履霜」」。完整配置 → `assets/example_kun_chuliu.json`。

## 换卦时

1. 联网核对新爻的爻辞与《象》；非乾、坤则 `src3: []`。
2. **先找这爻的常见误读**：搜一次白话解读，看大众版本怎么说（多半是励志化或道德化的）。找到落差就写翻转句；找不到明显误读，就抓爻辞里一个字做重译。
3. 按首行格式重写帖子：翻转句一到两句（别写成小论文）→ 具体处境、动作、画面 → 可选接续句 → 两个标签。不劝告、不总结，核字数 ≤275。
4. 复制一份 JSON，改卦名、卦象说明、六爻阴阳与本爻位置、原文、三条解读、对照行；**本爻为初爻时用对卦对举写对照行**。
5. 跑 `render_card.py`，看图复检。
6. 可直接选用成例：`example_92.json`（阳爻·得中）、`example_93.json`（阳爻·危地）、`example_kun_chuliu.json`（阴爻·初爻·有《文言》）。
7. **上爻（上九／上六）没有下一爻**，接续句改为回指初爻，或直接省掉。
