# 成例

五份成例、六条帖子，换卦时照此重写。卡片配置全文见 `assets/example_92.json`、`assets/example_93.json`、`assets/example_94.json`、`assets/example_kun_chuliu.json` 与 `assets/example_kun_liusan.json`。

三条约定贯穿全部成例：

1. 帖子末尾**只有标签**，不写「卦象与原文见图」。
2. 正文是**同路人的见闻，不是长辈的叮嘱**——只写处境、动作、画面，不劝告、不下指令、不写箴言。
3. 帖子要有一个**信息增量**：指出这爻常被怎么误读，再给出更准的读法。判断落在**文本**上，不落在读者身上。

第 3 条是这批成例改写的重点。详见 `conventions.md` 第 2 节。

八条贯穿所有成例的硬口径（也都是被用户否过之后才定下来的）：

- **先写本爻的重点**：动笔前先答一句——这一爻到底在说什么？重点常落在处境的断语上（`无咎`／`悔`／`厉`／`吉`／`凶`）。翻转（或单字重译）是说出重点的手段之一，不是必答题；**结尾收在重点上，不为效果硬造转折**。
- **一段是一段话，不是一行一句**：主体段要能一口气读下来；断行只留给转场（时间、场景换了），不为字面上的节奏把一句话掰成三行。
- **像说话**：句子要像日常聊天里会说的；书面缩略、文言腔、四字成语、倒装、生造短语一律改掉（「倒先」「美含在里头」「一天天走到的」「走到底的却是你」都属此列）。
- **翻转句说白话，判断是一句完整的话**：能单独转述给别人的才算判断；「变的只是名声」「没定，不算错」这类压缩短语，读者接住了也不知道拿它做什么。
- **主体从读者角度切入**：`桌上那份 offer 还没签，笔帽没拔` 胜过 `脚已经站到边上`。
- **场景连成一件事**：行与行之间答得上「所以呢／后来呢」，不是几张孤立画面的拼贴。
- **结尾用画面或判词收束**，判词也要完整成句；不写「再往上一步是九四」这类接续句。
- 篇幅吃紧时先删解释、再删形容词，**不删具体动作**。

这批帖子改过三轮。2026-11-16 一轮治「紧缩句拼贴＋压缩短语判断」；11-19 一轮治「书面腔」——句子完整了，可「倒先」「美含在里头」这种说法日常没人讲，读着还是绊；同一天用户又说「句子写的不通顺」，第三轮才发现病根是**断行**：为了节奏，把一句完整的话拆成三行，读者每行都要重新起步。这一轮把主体段并回整段，断行只留给转场。三轮病句与改法对照见 `conventions.md` 2.0～2.3。

## 例 1 · 乾卦九二

**帖子（主推，267 加权字符）**

```
乾 · 九二｜见龙在田，利见大人

「利见大人」常被当成去求贵人。其实正相反：本事摆在那里，是别人想来见你。

你还没升职，位子还在原处，名声先一步传出去了。
先是身边的人来找，后来听说的也来了。他们不是来求你办事，是来跟你聊手上的事。

见一面，来的人都有收获。

#周易 #乾卦
```

**手法拆解**：翻转句把「利见大人」从「去求贵人」掰回「别人来找你」——依据是《象》「德施普也」：德先让人看见，位子不用先动。主体不再一句一行，而是一段说完：没升职、名声先传出去 → 先来的是身边的人 → 后来听说的也来了 → 来的人都有收获。收束「见一面，来的人都有收获」落在「利见」的「利」上：见这件事本身就有用，不用等到被任用。旧版「本事摆到了明处，该是别人来见你」「谈定一件是一件」偏书面；再上一版把场景拆成三行，读着像诗，不像说话。

**备选 · 克制随笔版（241，无翻转、靠单字重译）**

```
乾 · 九二｜见龙在田，利见大人

「勿用」是没人用，「利见」是有人肯见。差的不是本事，是时候。

田不是朝堂，被看见也不等于被任用。
那阵子来往的多是同行，谈的都是手上的事。名字先传开了，位子还在后头，散席之后，照旧走回自己那间屋子。

#周易 #乾卦
```

「见」在这里被拆成「被看见」与「被任用」两层——一个字的重译，替代整段误读纠正。适合爻辞本身没有明显误读、但有字义落差的情况。开头的「勿用」「利见」先各自用一句白话说清（没人用／有人肯见），再下判断：**引文言必译**，不带解释的文言词是硬伤。旧版「中间隔着的不是本事，是时位」里的「时位」是术语，改成「差的不是本事，是时候」；这一轮又把三条短行并成一段，读起来才是一句话。

**卡片配置要点**：`hot_from_bottom: 2`、`hot_note: "◀ 本爻 · 得中"`；`trans1` 给「见龙在田，利见大人」的白话，`trans2` 给《象》的白话；`src3` 用《文言》节引一句并带「……」；三条「所处之位」讲下卦之中得中、二为臣位、出潜离隐。完整配置 → `assets/example_92.json`。

## 例 2 · 乾卦九三

**帖子（主推，271 加权字符）**

```
乾 · 九三｜君子终日乾乾，夕惕若厉，无咎

「终日乾乾」常被当成励志话。其实不是勤奋，是不敢停。

你爬到半山腰，往上看山顶还远，往下看回不去了。
白天干到天黑，夜里睡不踏实，没人替你兜底，稍微一松，之前爬的就白费了。

爻辞的判词是「无咎」：这么提着心走，不算错。

#周易 #乾卦
```

**手法拆解**：这一爻的重点是「危而无咎」——处境越险，越得提着心；真这么过下来，就没有过错。翻转只承担前半（「终日乾乾」不是勤奋，是不敢停），后半交给处境与判词：半山腰（往上看还远、往下看回不去，就是《文言》「上不在天，下不在田」的白话）→ 白天干到天黑、夜里睡不踏实 → 没人兜底，一松就白费。处境这一段现在是一句话连着说下来的，中间没有为了节奏硬断；旧版三行各自成句，读着像口号。结尾不收画面，落在爻辞自己的判词「无咎」上，读者读完知道这一爻到底给的是什么。

**卡片配置要点**：`hot_from_bottom: 3`、`hot_note: "◀ 本爻 · 重刚不中"`；「所处之位」三条按下卦之上／上不在天下不在田／进德修业来写；`src3` 选《文言》「九三重刚而不中，上不在天，下不在田」——这句本身就是讲爻位的，最贴「所处位置」主题。`trans1` 把「终日乾乾，夕惕若厉，无咎」翻成白话（整天勤勉不松劲，到夜里还提着心；虽在险处，也不至出错），`trans2` 翻《象》的「反复道也」。完整配置 → `assets/example_93.json`。

## 例 3 · 坤卦初六（阴爻／初爻／有《文言》）

覆盖三个易错点：全阴爻、本爻是第一爻（无前爻可对照）、坤卦有《文言》。

**帖子（273 加权字符）**

```
坤 · 初六｜履霜，坚冰至

这爻常被当成一句提醒，说小问题要早处理。其实它讲的是时间：从霜到冰，隔着一整个冬天。

踩到霜那天，天还没真冷，只是门槛边上白得早一点，谁也没当回事。
日子一天天过，地面越来越硬，也没人留意。

等河面冻实再回头看，才发现冰不是一天冻成的。

#周易 #坤卦
```

**手法拆解**：翻转先把误读说成人话：不是「防微杜渐」四个字，是「小问题要早处理」；落点放在时间上——霜到冰隔着一整个冬天，把教训变成时间差。主体两段，每段是一个时段：踩到霜那天（起）→ 之后那些日子（渐）。段与段之间靠「日子一天天过」接住，这是唯一该断行的地方——时间往前走了。收束「冰不是一天冻成的」，就是《象》「驯致其道」的白话，也是人人会说的那句老话，读者不用解任何词。上两版的「一天天走到的」（生造）与三行拆句（顿）都换掉了。

这份的收束是**判词**不是画面：它从《象》里读出来，不是作者的开解。不写「再往上一步是六二」，道理同前（2.3）。

**卡片配置要点**：六行 `yin: true`（阴爻画断开两段）；`hot_from_bottom: 1`；坤卦有《文言》，`src3` 用「……非一朝一夕之故，其所由来者渐矣」——讲「渐」，最贴初六见微知著的主题；初六无前爻，`bottom` 改**乾坤对举**「乾初九「潜龙勿用」 → 坤初六「履霜」」。`src2` 是全篇最长的一行（《象》两句），渲染后重点看图确认版面没被顶破；`trans2` 照它翻成白话。完整配置 → `assets/example_kun_chuliu.json`。

## 例 4 · 乾卦九四（读者角度 · 判词收束）

这一份是「朴实」与「从读者角度」两条口径的样板：全篇没有一个训诂术语，场景是读者桌上正在发生的事。

**帖子（274 加权字符）**

```
乾 · 九四｜或跃在渊，无咎

「或跃在渊」常被讲成进退自如。「或」其实是「也许」：可能跳上去，也可能不动。

桌上那份 offer 还没签，笔帽一直没拔，有人问起，只说要再看看。
夜里躺下，想的不是去了怎么干，是万一不成怎么回来。

爻辞的判词是「无咎」：试着往上跳，不算错。

#周易 #乾卦
```

**手法拆解**：

- **翻转只拆一个字**：「或」=「也许」（「可能跳上去，也可能不动」）。通行解读（百度百科、易德轩、高岛易断等）都把这爻讲成「审时度势、进退自如的从容」，可《文言》原话是「或之者，疑之也」——这里只留结论，不留训诂，**先删掉「《文言》说……」那半句，字数才是最省的**。
- **场景全在读者这一侧**，且一句话连着推：那份没签的 offer、没拔的笔帽 → 被问起只说再看看 → 夜里算的是退路。没有一句「他站在边上」；也不再是三个孤零零的短句。
- **收束用判词**：「无咎」译成「试着往上跳，不算错」。《象》「进无咎也」判的是「进」本身，不是「不定」；旧版「没定，不算错」既不是完整句，也判偏了。不写「再往上一步是九五：那一爻，在天上」——读者读完那两段就够了。

**卡片配置要点**：`hot_from_bottom: 4`；标题两行「或跃在渊／无咎」；`src3` 节引「九四重刚而不中……故或之。或之者，疑之也。」——中段「上不在天，下不在田，中不在人」被省掉，交给「所处之位」第二条讲；`trans2` 只译「进无咎也」（往前进一步，本身没有过错），不要加「审时而后进」这类增字。《文言》原话与帖子里的判词指向同一处，但不重复措辞。完整配置 → `assets/example_94.json`。

## 例 5 · 坤卦六三（阴爻／下卦之上／有《文言》）

覆盖：全阴爻居三、下卦之上的进退之际、对照行正常对举；`trans1` 放开到两行——「译文不限一行」口径的实测样例。

**帖子（271 加权字符）**

```
坤 · 六三｜含章可贞，或从王事，无成有终

「含章」常被理解成有才也别露。其实是把本事收着，该用的时候再用。

方案写了一个季度，交上去，署名写的是部门，有人问起，你也只说还在推进。
收尾没人愿意接，还是你做完的。

事成之后，功劳没记在你名下，可一路做到底的是你。

#周易 #坤卦
```

**手法拆解**：大众版把这爻讲成韬光养晦——才华收着，别锋芒太露，防的是上司疑忌。翻转只拆「含章」一个词，而且把误读也翻成了白话：「有才也别露」；正读「不是藏，是把本事收着，该用的时候再用」对应《象》「以时发也」。主体两段是一条事的两步：交方案、被问起（含）→ 没人接的收尾你接了（终）；两段之间是转折，断行就落在这里。收束是「无成有终」的白话：功劳不在你名下，可从开头做到结尾的是你——不引术语，也不倒装（旧版「走到底的却是你」）。

**卡片配置要点**：`hot_from_bottom: 3`；六行 `yin: true`；`src3` 节引「阴虽有美，含之以从王事，弗敢成也……地道无成，而代有终也」——前半讲含、后半讲终，正好接住爻辞两头。`trans1` 按「说得明白」放开写：47 字折两行，实测右栏余 44px；旧口径下这句会被压成约 20 字的概括。完整配置 → `assets/example_kun_liusan.json`。

## 换卦时

1. 联网核对新爻的爻辞与《象》，**并写下爻辞与《象》的白话译文**（`trans1` / `trans2`）；非乾、坤则 `src3: []`。
2. **先找这爻的常见误读**：搜一次白话解读，看大众版本怎么说（多半是励志化或道德化的）。找到落差就写翻转句；找不到明显误读，就抓爻辞里一个字做重译。**翻转句用白话写，像日常说话那样说，判断是一句完整的话，不搬训诂**。
3. **把处境换成读者的场景**：不问「这一爻在讲谁」，问「读者哪一天会撞上这件事」——跳槽、竞聘、被问要不要接、等一个还没下来的消息。挑一种就够，写具体的物（笔帽、闹钟、署名栏）。
4. 按首行格式重写帖子：翻转句一到两句（第二句的判断要完整成句）→ 读者能对上的场景（**一段是一段话，断行只留给转场**）→ **一句画面或判词收束，收在本爻的重点上**（判词也要完整成句）→ 两个标签。**帖子里每引一处文言词句，紧跟一句白话把它说清**；不劝告、不总结，核字数 ≤275。
5. 复制一份 JSON，改卦名、卦象说明、六爻阴阳与本爻位置、原文与译文、三条解读、对照行；**本爻为初爻时用对卦对举写对照行**。
6. 跑 `render_card.py`，看图复检：译文是否与原文逐句对应、是否说得明白（允许折行）、底部是否被裁。
7. 可直接选用成例：`example_92.json`（阳爻·得中）、`example_93.json`（阳爻·危地）、`example_94.json`（阳爻·上卦之下·重刚不中）、`example_kun_chuliu.json`（阴爻·初爻·有《文言》）、`example_kun_liusan.json`（阴爻·下卦之上·有《文言》）。
